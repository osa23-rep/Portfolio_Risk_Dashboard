# Portfolio Risk & Scenario Analysis Dashboard

An interactive Streamlit dashboard that analyzes portfolio risk across 50+ assets using Python, SQL, pandas, NumPy, Matplotlib, and Streamlit.

## Overview

This project evaluates portfolio performance and risk using key financial metrics, scenario analysis, correlation analysis, and rebalancing comparisons. The dashboard is designed to help users understand portfolio exposure under different market conditions.

## Features

- Tracks 50+ simulated assets across sectors
- Calculates volatility, Sharpe ratio, maximum drawdown, and Value-at-Risk
- Stress-tests portfolio exposure under market shock scenarios
- Models asset correlations and risk contributions
- Compares rebalancing strategies for risk-adjusted performance

## Tools Used

- Python
- SQL
- pandas
- NumPy
- Matplotlib
- Streamlit
